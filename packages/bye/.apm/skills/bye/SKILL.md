# Bye

A minimal example skill. Copy this folder to author your own.

## Instructions

When invoked, say goodbye to the user warmly and confirm in one line that the `bye`
skill from the `apm-demo` marketplace is installed and active.

Also tell the user a joke about leaving or goodbyes.
